Flatten Layer – chuyển ảnh 2D thành vector 1D

Chức năng: Chuyển đổi ma trận ảnh 2D thành vector 1D

Thông tin chuyển đổi:

• Input: Tensor (batch_size, 1, 28, 28)

• Output: Tensor (batch_size, 784)

• Công thức: Reshape từ ma trận 28×28 thành vector 784 phần tử

class Flatten:

⠀⠀⠀⠀def __init__(self, start_dim=1, end_dim=-1):

⠀⠀⠀⠀⠀⠀⠀⠀self.start_dim = start_dim

⠀⠀⠀⠀⠀⠀⠀⠀self.end_dim = end_dim

⠀⠀⠀⠀⠀⠀⠀⠀self.input_shape = None

⠀⠀⠀⠀def forward(self, x):

⠀⠀⠀⠀⠀⠀⠀⠀self.input_shape = x.shape

⠀⠀⠀⠀⠀⠀⠀⠀return x.view(x.size(0), -1) # (N, 784)

⠀⠀⠀⠀def backward(self, grad_out):

⠀⠀⠀⠀⠀⠀⠀⠀return grad_out.view(self.input_shape)
