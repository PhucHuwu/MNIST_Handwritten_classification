Pipeline tiền xử lý ảnh

Mục tiêu: Chuẩn hóa kích thước, thang giá trị, giúp hội tụ nhanh

from torchvision import transforms

⠀

transform = transforms.Compose([

⠀⠀⠀⠀transforms.Resize((28, 28)), # Chuẩn hóa kích thước

⠀⠀⠀⠀transforms.ToTensor(), # [0,255] -> [0,1], shape (1,28,28)

⠀⠀⠀⠀transforms.Normalize((0.5,), (0.5,)) # [0,1] -> [-1,1]

])

Quá trình áp dụng:

• Training: 60,000 ảnh → transforms → DataLoader

• Testing: 10,000 ảnh → transforms → DataLoader

• GUI: vẽ → resize → transforms → model

Giải thích chi tiết các bước:

1

Resize (28×28)

• Đồng nhất kích thước tất cả ảnh đầu vào

• Ảnh nhỏ giúp giảm số tham số mô hình

• Kết quả: 784 pixel đầu vào (28×28)

2

ToTensor

• Chuyển PIL Image/NumPy array → PyTorch tensor

• Scale pixels từ [0, 255] → [0, 1]

• Chuyển HWC (Height×Width×Channel) → CHW (Channel×Height×Width)

3

Normalize

• Công thức: output = (input - mean) / std

• Mean = 0.5, Std = 0.5 → Scale từ [0, 1] → [-1, 1]

• Lợi ích: Giúp model hội tụ nhanh hơn, tránh vanishing gradient, cải thiện độ chính xác
