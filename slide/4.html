Kiến trúc mạng Neural Network

Cấu trúc chi tiết mạng neural

Tổng quan kiến trúc

• Mạng neural đa lớp (MLP) hoàn toàn kết nối

• Mô hình xây dựng từ đầu (from scratch)

• Input: Ảnh grayscale 28×28 → vector 784 phần tử

• Output: Vector xác suất 10 lớp (chữ số 0-9)

Thống kê tham số

• Tổng số tham số: 235,146

• Layer 1: 784×256 + 256 = 200,960 tham số

• Layer 2: 256×128 + 128 = 32,896 tham số

• Layer 3: 128×10 + 10 = 1,290 tham số

Lý do chọn kiến trúc

• Minh họa rõ forward/backward propagation

• Cân bằng giữa hiệu suất và độ phức tạp

• Phù hợp học tập flow gradient qua mạng

Sơ đồ kiến trúc

Input Image (28×28)

Flatten Layer (784)

Linear Layer 1 (784 → 256)

ReLU Activation

Linear Layer 2 (256 → 128)

ReLU Activation

Output Layer (128 → 10)

Softmax Activation

Output (10 lớp xác suất: 0 - 9)
