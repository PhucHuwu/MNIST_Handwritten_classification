ReLU Activation

Công thức: Rectified Linear Unit (ReLU)

Code implementation:

class ReLU:

⠀⠀⠀⠀def __init__(self):

⠀⠀⠀⠀⠀⠀⠀⠀self.input_cache = None

⠀

⠀⠀⠀⠀def forward(self, x):

⠀⠀⠀⠀⠀⠀⠀⠀self.input_cache = x.clone()

⠀⠀⠀⠀⠀⠀⠀⠀return torch.clamp(x, min=0)

⠀

⠀⠀⠀⠀def backward(self, grad_output):

⠀⠀⠀⠀⠀⠀⠀⠀mask = (self.input_cache > 0).float()

⠀⠀⠀⠀⠀⠀⠀⠀return grad_output * mask

Hoạt động của ReLU:

1

Forward Pass

• Đầu vào dương: giữ nguyên giá trị

• Đầu vào âm: chuyển thành 0

• Công thức: f(x) = max(0, x)

2

Backward Pass

• Gradient cho x > 0: 1 (truyền nguyên gradient)

• Gradient cho x ≤ 0: 0 (chặn gradient flow)

• f'(x) = { 1 nếu x > 0; 0 nếu x ≤ 0 }

Ưu điểm của ReLU:

Tính toán nhanh hơn sigmoid/tanh (chỉ cần phép so sánh)

Giảm thiểu vanishing gradient (gradient không bị nén nhỏ)

Sparse activation (nhiều neuron = 0, giúp mô hình thưa)

Hội tụ nhanh hơn sigmoid/tanh (6 lần theo nghiên cứu)

Biological plausibility (hoạt động giống neuron thật)
