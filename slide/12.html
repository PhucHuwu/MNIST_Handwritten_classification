Quy trình Training

Cấu hình:

Epochs: 100 (tối đa)

Batch size: 64

Early stopping: patience = 10, min_delta = 0.0001

Optimizer: Adam (lr = 0.001)

Training loop:

for epoch in range(max_epochs):

⠀⠀⠀⠀# 1. Forward pass

⠀⠀⠀⠀output = model.forward(images)

⠀⠀⠀⠀# 2. Compute loss

⠀⠀⠀⠀loss = loss_fn.forward(output, labels)

⠀⠀⠀⠀# 3. Backward pass

⠀⠀⠀⠀grad = loss_fn.backward()

⠀⠀⠀⠀model.backward(grad)

⠀⠀⠀⠀# 4. Update parameters

⠀⠀⠀⠀optimizer.step(model.get_gradients())

⠀⠀⠀⠀# 5. Evaluate on validation set

⠀⠀⠀⠀val_acc = evaluate(model, val_loader)

⠀⠀⠀⠀# 6. Save best model

⠀⠀⠀⠀if val_acc > best_acc:

⠀⠀⠀⠀⠀⠀⠀⠀save_checkpoint(model, optimizer, epoch)

Quy trình chi tiết:

1

Khởi tạo

• Khởi tạo mạng, hàm loss, optimizer

• Chuẩn bị DataLoader cho training/validation

• Biến theo dõi: best_acc, no_improvement_count

2

Training cycle

• Forward: input → model → output → loss

• Backward: loss gradient → backprop → update params

• Đánh giá: validation accuracy sau mỗi epoch

3

Checkpointing

• Lưu model khi validation accuracy cải thiện

• Checkpoint bao gồm: state các layer, optimizer, metrics

• Model tốt nhất: Epoch 18, validation accuracy 96.53%

4

Early Stopping

• Dừng training khi không có cải thiện sau 10 epochs

• Tránh overfitting, tiết kiệm thời gian

• Thực tế: dừng sau 28 epochs (early stopping tại epoch 28)
